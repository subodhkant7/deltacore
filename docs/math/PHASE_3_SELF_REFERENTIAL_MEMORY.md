# Phase 3 Mathematical Specification: Minimal Self-Referential Adaptive Memory

This document specifies the mathematical formulations for the self-referential adaptive memory system introduced in **DeltaCore Phase 3**.

---

## 1. Taxonomic Distinction: From Adaptive to Self-Referential

DeltaCore strictly distinguishes between three structural levels of learning rate control:

1. **Fixed Update**:
   $$\eta_t = \eta_0 = \text{constant}$$
   *(Static hyperparameter across the entire sequence).*

2. **Adaptive Update**:
   $$\eta_t = f_\theta(z_t)$$
   *(External parameterization $\theta$ conditioned on current input $x_t$, residual $e_t$, or state norm $\|M_t\|_F$. Note: $\theta$ remains static during inference).*

3. **Self-Referential Update**:
   $$\eta_t = f(C_t, z_t)$$
   where $C_t$ is an internal **dynamics memory state** that evolves during inference:
   $$C_{t+1} \neq C_t$$
   The controller state is itself updated online based on performance telemetry and feedback.

> **Principle**: Reading the content memory $M_t$ is NOT sufficient to call a model "self-referential". A system is only self-referential if the state that modulates the learning dynamics itself evolves online ($C_{t+1} = \mathcal{U}(C_t, \dots)$) as part of the recurrent state machine.

---

## 2. Minimal Two-Memory Coupled Recurrence

Phase 3 implements a coupled two-memory dynamical system:

```
               Key (k_t) ─────────────┐
                                      ▼
Target (v_t) ──> [ Error e_t ] ──> [ Features z_t ]
                        │                     │
                        │                     ▼
                        │              [ Dynamics Memory C_t ]
                        │                     │
                        │                     ▼
                        │             Control Signal (r_t)
                        │                     │
                        │                     ▼
                        │             Step Size (\eta_t)
                        │                     │
                        ▼                     ▼
           [ Content Memory M_t ] ◄── Delta Update (\Delta M_t)
                        │
                        ▼
                 Output (\hat{v}_t)
```

### 2.1. Memory 1 — Content Memory State ($M_t$)
Stores input-output associative bindings:

$$
M_t \in \mathbb{R}^{V \times K}
$$

1. **Read Prediction**:
   $$\hat{v}_t = M_t k_t \in \mathbb{R}^V$$

2. **Prediction Residual**:
   $$e_t = v_t - \hat{v}_t \in \mathbb{R}^V$$

3. **State Transition**:
   $$M_{t+1} = M_t + \eta_t e_t k_t^\top \in \mathbb{R}^{V \times K}$$

where $\eta_t \in \mathbb{R}_{> 0}$ is dynamically generated by the second memory $C_t$.

---

### 2.2. Memory 2 — Dynamics Memory State ($C_t$)
Generates the control signal driving the content memory's step size:

$$
C_t \in \mathbb{R}^{R \times D_c}
$$

For a scalar step-size controller, $R = 1$, yielding:

$$
C_t \in \mathbb{R}^{1 \times D_c}
$$

where $D_c \in \mathbb{N}^+$ is the control feature dimension.

#### Control Feature Vector ($z_t$)
Features extracted from observable inference state at step $t$:

$$
z_t = \begin{bmatrix} \|e_t\|_2 \\ \|M_t\|_F \\ 1.0 \end{bmatrix} \in \mathbb{R}^3 \quad (D_c = 3)
$$

The bias term ($1.0$) allows $C_t$ to learn affine baseline step sizes.

#### Readout (Control Signal & Step Size)
The dynamics memory projects $z_t$ into scalar response $r_t \in \mathbb{R}$:

$$
r_t = C_t z_t = \sum_{j=1}^{D_c} C_{t, 1j} z_{t, j} \in \mathbb{R}
$$

The effective step size is obtained via bounded squashing:

$$
\eta_t = \eta_{\max} \cdot \sigma(r_t) \in (0, \eta_{\max}]
$$

---

## 3. Online Evolution of the Dynamics Memory

To satisfy the self-referential requirement ($C_{t+1} \neq C_t$), $C_t$ evolves via DeltaCore's standard delta-rule update applied to an explicit control target:

### 3.1. Target Generator ($h$)
An explicit component generates a desired dynamics target $c_t^{\text{target}} \in \mathbb{R}$:

$$
c_t^{\text{target}} = h(e_t, k_t, v_t, M_t, C_t)
$$

For the Phase 3 reference implementation, we use an error-driven target signal:

$$
c_t^{\text{target}} = \alpha \cdot \|e_t\|_2 + \beta
$$

where $\alpha \ge 0$ scales with error urgency and $\beta$ sets the resting target.

> **Design Rule**: $c_t^{\text{target}}$ must NOT be hardcoded to the optimal learning rate of the downstream task. That would make the experiment circular. It is an observable feedback signal driving dynamics.

### 3.2. Dynamics State Transition
Using the prediction $r_t = C_t z_t$ and target $c_t^{\text{target}}$, the dynamics prediction residual is:

$$
e_{C, t} = c_t^{\text{target}} - C_t z_t \in \mathbb{R}
$$

The dynamics memory transitions via the delta update rule:

$$
\Delta C_t = \rho_t \cdot e_{C, t} z_t^\top \in \mathbb{R}^{1 \times D_c}
$$

$$
C_{t+1} = C_t + \Delta C_t = C_t + \rho_t (c_t^{\text{target}} - C_t z_t) z_t^\top
$$

where $\rho_t \ge 0$ is the learning rate of the dynamics memory (meta-step size).

---

## 4. Complete Coupled Step Sequence

At each discrete time step $t$:

1. **Content Prediction**: $\hat{v}_t = M_t k_t$
2. **Content Error**: $e_t = v_t - \hat{v}_t$
3. **Feature Construction**: $z_t = [\|e_t\|_2, \|M_t\|_F, 1.0]^\top$
4. **Dynamics Readout**: $r_t = C_t z_t$
5. **Step Size Computation**: $\eta_t = \eta_{\max} \sigma(r_t)$
6. **Content State Transition**: $M_{t+1} = M_t + \eta_t e_t k_t^\top$
7. **Dynamics Target**: $c_t^{\text{target}} = \alpha \|e_t\|_2 + \beta$
8. **Dynamics Error**: $e_{C, t} = c_t^{\text{target}} - r_t$
9. **Dynamics State Transition**: $C_{t+1} = C_t + \rho_t e_{C, t} z_t^\top$

---

## 5. Non-Mutating Functional Semantics

The coupled state is packaged as:

$$
\mathcal{S}_t = (M_t, C_t)
$$

The transition operator $\mathcal{T}: (k_t, v_t, \mathcal{S}_t) \to (\hat{v}_t, \mathcal{S}_{t+1})$ produces a new tuple $\mathcal{S}_{t+1} = (M_{t+1}, C_{t+1})$ without in-place mutation of $M_t$ or $C_t$.

---

## 6. Scientific Disclaimer

> **Explicit Notice**:
> Phase 3 proves that a minimal self-referential state machine can be implemented, differentiated, and observed.
> It does NOT claim stability, asymptotic convergence, or superiority over fixed or adaptive baselines.
> Self-referential feedback loops can induce state drift, oscillatory step sizes, or runaway divergence when $\rho_t$ is miscalibrated. Rigorous stability constraints are addressed in **Phase 4**.
