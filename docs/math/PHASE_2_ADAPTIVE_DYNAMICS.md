# Phase 2 Mathematical Specification: Adaptive Update Dynamics

This document specifies the mathematical formulations for the adaptive step-size controllers and state transitions introduced in **DeltaCore Phase 2**.

---

## 1. Foundational Taxonomy: Three Distinct Levels of State Dynamics

To maintain conceptual and scientific rigor (Principle A of the DeltaCore Constitution), DeltaCore explicitly distinguishes between three levels of state transition mechanics:

1. **Fixed Update**:
   The step size $\eta$ is an invariant, static hyperparameter throughout the sequence:
   $$\eta_t = \eta_0 = \text{constant}$$
   *(This was the Phase 1 reference baseline).*

2. **Adaptive Update**:
   The step size $\eta_t$ is dynamically computed at each discrete step $t$ as a function of currently available input, target, error, or state telemetry:
   $$\eta_t = f_\theta(z_t)$$
   where $z_t$ is an explicit input or state feature (e.g. key vector $k_t$, prediction error $e_t$, or Frobenius norm $\|M_t\|_F$).

3. **Self-Referential Update**:
   A specific subtype of adaptive dynamics where the modulation signal is actively generated by the evolving memory / meta-learned associative state process itself (e.g. a second recurrent memory predicting learning rates or retention factors, as in HOPE / VisionHOPE / SRNL).

> **Rule**: Do **not** call every adaptive controller "self-referential". Controller B (input-conditioned) and Controller C (error-conditioned) are **adaptive**, not self-referential. Conflating generic adaptivity with self-referential meta-learning obscures architectural attribution.

---

## 2. Core Transition Formulation

Let $M_t \in \mathbb{R}^{V \times K}$ be the associative memory at step $t$, $k_t \in \mathbb{R}^K$ the query/key, and $v_t \in \mathbb{R}^V$ the target value.

The retrieval prediction and residual error are:

$$
\hat{v}_t = M_t k_t \in \mathbb{R}^V
$$

$$
e_t = v_t - \hat{v}_t = v_t - M_t k_t \in \mathbb{R}^V
$$

The state transition is:

$$
M_{t+1} = M_t + \eta_t \, e_t k_t^\top \in \mathbb{R}^{V \times K}
$$

where $\eta_t \in \mathbb{R}_{\ge 0}$ is computed dynamically by an explicit step-size controller.

## 3. Reference Controllers

Phase 2 establishes four reference controllers to evaluate different informational dependencies for $\eta_t$:

### 3.1. Controller A — Constant Step Size (Fixed Baseline)

$$
\eta_t = \eta_0
$$

- **Dependencies**: None (static parameter $\eta_0 \ge 0$).
- **Output Range**: $\eta_t = \eta_0$.
- **Role**: Serves as the Phase 1 backward-compatible baseline.

### 3.2. Controller B — Input-Conditioned Step Size

The step size is modulated by features of the current input vector $x_t$ (e.g. key $k_t \in \mathbb{R}^K$):

$$
\eta_t = \eta_{\max} \cdot \sigma(w^\top x_t + b)
$$

where:
- $w \in \mathbb{R}^K$ is a learnable or fixed weight vector.
- $b \in \mathbb{R}$ is a scalar bias.
- $\sigma(z) = \frac{1}{1 + e^{-z}}$ is the standard sigmoid activation.
- $\eta_{\max} > 0$ defines the strict upper bound on step magnitude.
- **Dependencies**: $x_t$ (input / key features). Independent of memory $M_t$ or target $v_t$.
- **Output Range**: $0 < \eta_t < \eta_{\max}$.

### 3.3. Controller C — Error-Conditioned Step Size

The step size scales with the Euclidean magnitude of the prediction residual $\|e_t\|_2$:

$$
\eta_t = \eta_{\max} \cdot \sigma(a \|e_t\|_2 + b)
$$

where:
- $\|e_t\|_2 = \sqrt{\sum_{i=1}^V e_{t, i}^2 + \epsilon}$ (with small $\epsilon \ge 0$ for stable autograd at zero).
- $a, b \in \mathbb{R}$ are scalar modulation parameters.
- $\eta_{\max} > 0$ is the maximum allowable step size.
- **Dependencies**: Current retrieval error $e_t = v_t - M_t k_t$.
- **Intuition**: When error is large (e.g. following a distribution shift), $\eta_t$ can scale up to accelerate adaptation; when error approaches zero, $\eta_t$ can decrease to preserve memory.
- **Output Range**: $0 < \eta_t < \eta_{\max}$.

### 3.4. Controller D — State-Conditioned Step Size

The step size depends on the Frobenius norm of the current memory matrix $\|M_t\|_F$:

$$
\eta_t = \eta_{\max} \cdot \sigma(a \|M_t\|_F + b)
$$

where:
- $\|M_t\|_F = \sqrt{\sum_{i=1}^V \sum_{j=1}^K M_{t, ij}^2 + \epsilon}$.
- $a, b \in \mathbb{R}$ are scalar scaling parameters.
- **Intuition**: Can be configured to dampen updates as memory norm increases ($a < 0$), acting as a soft saturation control. (Note: Damping requires $a < 0$; if $a > 0$, updates amplify as $\|M_t\|_F$ grows. Damping is an effect of parameter sign, not an intrinsic property of state conditioning).
- **Output Range**: $0 < \eta_t \le \eta_{\max}$.

## 4. Scientific Honesty & Comparison Discipline

> **Explicit Warning**:
> Controller comparisons in Phase 2 are **exploratory empirical investigations**, not evidence of general superiority.
>
> We do not claim that any adaptive controller is superior to fixed Delta learning. Depending on the task, noise level, and sequence length, adaptive controllers can exhibit non-linear oscillation, under-adaptation, or delayed convergence compared to well-tuned constant step sizes. All claims must be grounded in verified benchmark measurements.
