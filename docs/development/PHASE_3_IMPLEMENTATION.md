## 1. Executive Summary

Phase 3 introduces the first genuinely **self-referential adaptive memory system** into DeltaCore.

The fundamental architectural evolution across phases is:
- **Phase 1**: Fixed delta update: $M_{t+1} = M_t + \eta e_t k_t^\top$ with constant $\eta$.
- **Phase 2**: Adaptive delta update: $M_{t+1} = M_t + \eta_t e_t k_t^\top$ where $\eta_t = f(z_t)$ is generated by an external, non-evolving controller.
- **Phase 3**: Self-referential coupled memory: $M_{t+1} = M_t + \eta_t e_t k_t^\top$ where $\eta_t = f(C_t, z_t)$ is generated by a **dynamics memory $C_t$ that itself co-evolves online** via delta-rule learning:
  $$C_{t+1} = C_t + \rho_t (c_t^{\text{target}} - C_t z_t) z_t^\top$$

The implementation strictly prioritizes architectural separation, functional non-mutating state semantics, end-to-end autograd differentiability, operational recovery latency quantification, and scientific honesty (no speculative stability guards or premature claims).

## 3. Mathematical Contract Implemented

The minimal coupled two-memory recurrence implemented in `SelfReferentialSystem` is:

### Content Memory $M_t \in \mathbb{R}^{V \times K}$
1. Content Prediction:
   $$\hat{v}_t = M_t k_t$$
2. Prediction Residual Error:
   $$e_t = v_t - \hat{v}_t$$
3. Content Memory Update:
   $$M_{t+1} = M_t + \eta_t e_t k_t^\top$$

### Dynamics Memory $C_t \in \mathbb{R}^{R \times D_c}$ ($R=1, D_c=3$)
4. Control Features:
   $$z_t = \begin{bmatrix} \|e_t\|_2 \\ \|M_t\|_F \\ 1.0 \end{bmatrix} \in \mathbb{R}^3$$
5. Dynamics Readout:
   $$r_t = C_t z_t \in \mathbb{R}^1$$
6. Step Size Modulation:
   $$\eta_t = \eta_{\max} \sigma(r_t) \in (0, \eta_{\max})$$
7. Dynamics Control Target:
   $$c_t^{\text{target}} = \alpha \|e_t\|_2 + \beta \in \mathbb{R}^1$$
8. Dynamics Residual Error:
   $$\Delta r_t = c_t^{\text{target}} - r_t$$
9. Dynamics Memory Update:
   $$C_{t+1} = C_t + \rho_t (c_t^{\text{target}} - C_t z_t) z_t^\top$$

## 8. Stability Observations

In accordance with Phase 3 specifications, **no speculative stability controllers, spectral clamps, or projection guards were added**:

1. **Unbounded Rank-1 Updates**: The dynamics memory update $\Delta C_t = \rho (c_t^{\text{target}} - C_t z_t) z_t^\top$ scales quadratically with $\|z_t\|$. When keys are unnormalized or error remains persistently large (e.g. alternating conflicting targets), $\|C_t\|$ can grow rapidly.
2. **Aggressive Learning Rates**: Under $\rho = 2.0$, state growth accelerates and can lead to floating-point overflow (`inf`/`nan`).
3. **Passive Observability**: The `finite_state` flag in `measure_step_telemetry` detects and exposes these numerical events without masking them. A genuine divergence provides valuable empirical data for designing Phase 4 stability controls.
